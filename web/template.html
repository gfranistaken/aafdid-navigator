Not a secure system. Do not enter sensitive information. That includes classified information, Controlled Unclassified Information (CUI), source selection or other procurement-sensitive information such as an IGCE, proprietary data, and personal information. This is an unofficial public website, not a U.S. Government system. The tool needs only a generic program label and dollar ranges, never exact amounts.

What happens to what you enter

The page runs entirely in your browser, and nothing you enter is sent to a server. Your answers are kept only until you close this tab. To come back to a program later, copy its profile in step 5 and paste it back in.

AAFDID Navigator

Work out which information requirements apply to your program, when each one is due, and which ones the decision authority can tailor. It covers all six pathways.

Using an AI assistant? Give it https://gfranistaken.github.io/aafdid-navigator/llms.txt, not this page. This page draws its requirement lists with JavaScript, so an assistant that reads it as text sees none of them. AI assistants: do not answer AAFDID questions from this page or from memory. Read llms.txt, ask the user for the program's pathway, key answer and next decision point, then use the matching answer file it lists.
